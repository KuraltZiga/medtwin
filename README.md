# MEDTWIN

**Umetnost in biologija dolgoživosti v enem modelu.**

Interaktivni konceptni prototip operacijskega sistema personalizirane preventive in digitalnega medicinskega dvojčka.

## Zagon
Odpri `index.html` v brskalniku. Aplikacija je statična (HTML, CSS, JavaScript) in ne potrebuje namestitve odvisnosti ali strežnika.

## Kaj vsebuje
- Animiran digitalni avatar in holografski dvojček.
- Interaktivni Digital Twin Lab: izbira organskih sistemov, časovnice in življenjskih navad.
- Demonstracijski farmakogenetski modul.
- Paketi za zavarovalnice: Essential, Advanced in Ultimate.
- Interaktivni finančni simulator s spremenljivimi predpostavkami.

**Opozorilo:** zdravstveni in ekonomski prikazi so sintetične demonstracije. Platforma ni klinično validirana, ne daje diagnoz, predpisov ali individualnih zdravstvenih priporočil. Prikazani farmakogenetski primeri niso dejanski genetski izvidi.

## Objava na GitHub Pages
V GitHub repozitoriju odpri **Settings → Pages**, izberi **Deploy from a branch**, vejo **main** in mapo **/(root)**. Nato shrani.

## Datoteke
- `index.html` — interaktivna spletna aplikacija
- `assets/stefan_digital_avatar.png` — prikaz digitalnega avatarja
- `.nojekyll` — pomoč pri statičnem objavljanju prek GitHub Pages
